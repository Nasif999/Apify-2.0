Questions, answered

Do I need to know how to code?+
No. Install the Chrome extension, click record, do the task once normally, then click stop. Apify figures out the rest.
What happens if a website changes its layout?+
Apify re-scans the live page on every run and falls back to matching elements by label text if a selector shifts, so most layout tweaks don't break your automation.
Can I change inputs before each run?+
Yes. Every recorded field — destinations, dates, quantities, filters — becomes an editable input on your dashboard before you hit run.
Is my login data safe?+
Saved sessions are stored locally and only reused by your own automation runs — they're never sent to a third party.
